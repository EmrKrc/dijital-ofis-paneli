API ve entegrasyon merkezi

Platform servisleri, dış sağlayıcılar, webhook'lar ve güvenli anahtar yönetimi. Kayıtlı olması, dış API'nin canlı bağlandığı anlamına gelmez.
Güvenlik kuralı: API anahtarı, parola, token veya sertifika içeriği bu ekrana ya da veritabanına yazılmaz. Gizli değerler yalnızca ilgili sunucu/Edge Function ortamında saklanır. Aşağıdaki kayıt tablosu sağlayıcı ve bağlantı metaverisini tutar.

AI veri paylaşımı ilkesi

AI servisine yalnızca kullanıcının talep ettiği ve gerekli bağlam gönderilir. Üretim ortamında müşteri onayı, veri minimizasyonu ve sözleşme şartları doğrulanmadan kişisel veya ticari sır içeren belge metni gönderilmemelidir.

OpenAI API kullanımı, ChatGPT aboneliğine dahil değildir. Ayrı API anahtarı ve kullanım bazlı faturalama gerekir. İsterseniz AI özelliğini kapalı tutup kural tabanlı kontrolü kullanabilirsiniz.
